# Type icons

The 18 Pokémon type icons, white on transparent, from
https://github.com/duiker101/pokemon-type-svg-icons ("Very simple set of SVG icons for Pokemon
types for any use", after https://dribbble.com/shots/4862612-Pokedex-iOS-app). Fetched 2026-10-24.
`src/lib/TypeIcon.svelte` sets one in a circle of its type's colour.
